# Code Generation
## Introduction
This document describes the code generation process.

## Environment Variables
The following environment variables are required for code generation:
* GITHUB_TOKEN
* GITHUB_REPOSITORY
* GITHUB_EVENT_PATH
* ISSUE_NUMBER
* ISSUE_TITLE
* ISSUE_BODY

## Prompt Files
The following prompt files are required:
* auto-fix-system.md
* generation-user.md
