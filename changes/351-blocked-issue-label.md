### Changed
- Issue validation applies a `blocked` label (ADR-0067) instead of `needs-refinement` when the only blockers are B4 and the body declares a `## Blocked by` section; `manage_labels.mjs` applies exactly one of `ready-for-dev`, `needs-refinement` and `blocked` and reads the new optional `IS_BLOCKED` env from `adl-validate-issue.yml`. A repository using the pipeline gets the new `blocked` label created on its next validation or `ensure_labels` run; code generation is unchanged (only a valid issue starts it). The feature issue template gains an optional `Blocked by` section and the flow dashboards show the validation decision as `Blocked`.
